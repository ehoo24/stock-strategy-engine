# W 底与 MACD 绿柱收缩

运行 `npm run strategy:w-macd`，使用当前数据库中的可交易股票快照和前复权日线，并保存本次结果。此策略不远程补齐行情，不使用涨幅、换手率或成交额粗筛，也不受原放量趋势策略的 80 只粗筛上限限制。

`npm run pipeline:w-macd` 会先请求并刷新快照，日线仍只读取本地数据。日线需要另外同步；新策略运行时不会自动下载。

## 识别口径

以各股最后一根日线为基准，向前取含当日的 90 个自然日，通常约 60 根日线。更早的日线只参与 MACD 预热；默认最多读取 140 根，可通过现有 `STOCK_STRATEGY_BAR_LIMIT` 调整。至少需要 60 根本地日线，窗口内至少 35 根，第一段负柱起点还需要已有 26 根前置数据。覆盖不足会在运行结果中报告。

MACD 沿用项目的 12/26/9 参数，柱值为 `2 × (DIF - DEA)`。绿柱定义为柱值小于零，面积为连续负柱绝对值之和，不依赖行情软件的配色或图像像素。两段负柱必须完整处于窗口内，不能把跨窗口的第一段柱体截短后计算面积。

W 底使用两个局部低点，中间至少有 2% 的反弹，之前有至少 3% 的高点回落。局部低点需不高于左右各两根 K 线的最低价，两个低点分别对应最近两段有效负柱，每段至少三根柱。不足三根的短段作为噪声跳过，段内仍只累加实际连续负柱，不跨越红柱合并面积。第二段面积必须小于第一段。

第二低点最多距今 15 根日线，之后不能再创新低，最新收盘需比该低点高至少 1%。这些条件用于避免把已破位或很早之前的 W 底列为当前候选。

## 严格符合与相似观察

| 条件 | 严格符合 | 相似观察 |
| --- | --- | --- |
| 两底间隔 | 8–30 根日线 | 8–45 根日线 |
| 第二低点位置 | 较第一低点不低于 -2%，持平或抬高更优 | 不低于 -5% |
| 中间反弹高点 | 超过前高时提示，不作为排除条件 | 同左 |
| DIF、DEA 零轴表现 | 两段负柱及中间阶段均不下穿零轴 | 下穿最多 20 根，最低线值不低于 -0.75 倍区间平均真实波幅 |
| 当前 MACD | 第二段结束、柱体非负、双线较上一日同步上升 | 允许未完全确认，输出具体原因 |
| 颈线突破 | 单独展示，无须强制突破 | 单独展示，无须强制突破 |

零轴下穿深度按两段负柱覆盖区间的平均真实波幅归一化，因此不同价位的股票使用同一口径。真实波幅取当日高低差、当日最高与前收差、当日最低与前收差的绝对值最大值。

相似组若第二段负柱尚未结束，面积比会明确标注为暂时值，后续负柱增长可能使其不再符合。评分仅用于同组形态排序，严格组始终排在相似组之前，不表示收益率或胜率。

## 结果与限制

每只候选记录形态窗口、前高、两底与颈线日期价格、两段负柱的日期及面积、面积比、零轴下穿数量和归一化深度、当前 MACD 确认情况。CLI 分组显示，并输出快照时间、日线截至日期与覆盖警告。

结果覆盖范围由本地已有日线决定；没有日线的股票不会被判定为不符合。不同股票日线截止时间可能不同，不能把旧数据的命中视为今日行情信号。策略是确定性的形态筛选，尚未通过历史回测验证收益表现。

## 阶段雷达

运行 `npm run strategy:w-macd-radar` 可筛选仍在演化中的形态。它和确认形态策略分开，避免把未确认信号混入严格匹配：

- 左侧观察：第二次回落没有跌破第一底，第二段负柱累计面积仍小于第一段，并出现负柱收缩。第二底为截至信号日的暂定最低价，不使用其后 K 线确认。
- 微右侧确认：局部微反弹高点已经在前一日或更早由后续 K 线确认，当前收盘突破该高点，同时 MACD 改善且仍未到整段颈线。
- 颈线突破：收盘突破两底间最高价，突破日成交量至少为此前 20 日均量的 1.2 倍。

当前信号最多保留 5 根日线，第一底被第二次回落跌破即失效。阶段雷达提供暂定低点、两级失效位、颈线空间、ATR 倍数、未闭合负柱面积、量能和计划盈亏比。健康度评分由动能 40 分、结构 40 分、可观察量价 20 分构成，仅用于排序，不是上涨概率，也不将成交量变化解释为特定资金身份。

`replayWMacdRadar` 会按日线前缀逐日重放，每一天只读取当天及以前的数据，为后续验证预留。计划事件口径为信号后下一交易日开盘观察，未来 10 个交易日内先达到 +5%，还是先触及局部失效位；在完成独立样本校准前，界面不展示胜率。
